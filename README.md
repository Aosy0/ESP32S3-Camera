# ESP32-S3 Camera Auto Save to SD Card

XIAO ESP32S3 Sense用の自動撮影・SDカード保存プログラムです。10分ごとに自動撮影し、SDカードに保存します。Webブラウザから画像閲覧・管理も可能です。

## 機能

- **自動撮影**: 10分間隔で自動的に撮影
- **SDカード保存**: タイムスタンプ付きファイル名で保存
- **Webギャラリー**: ブラウザからライブストリーム表示・画像閲覧
  - ライブストリーム（ポート81）
  - 解像度・グレースケール切り替え
  - ワンクリックキャプチャ（SDに自動保存）
  - SDカード画像の一覧表示・削除・ダウンロード
  - 一括選択・一括ダウンロード・一括削除機能
- **WiFi + NTP**: 正確な日時情報を取得
- **安定動作**: VGA解像度で安定した長時間動作
- **状態監視**: シリアルモニタでステータス確認可能

## 必要なハードウェア

- Seeed Studio XIAO ESP32S3 Sense
- XIAO ESP32S3 Sense 拡張基板
- **外部WiFiアンテナ（必須）**
- microSDカード（FAT32フォーマット、2-32GB推奨）
- WiFi環境（2.4GHz）

> [!IMPORTANT]
> **外部アンテナは必須です**。XIAO ESP32S3にアンテナを接続しないと、WiFi接続が非常に不安定になり、正常に動作しません。必ずアンテナを取り付けてください。

## セットアップ

### 1. WiFi設定ファイルの作成

`src/config.h.example` をコピーして `src/config.h` を作成し、WiFi情報を入力：

```cpp
const char* WIFI_SSID = "あなたのWiFi名";
const char* WIFI_PASSWORD = "あなたのWiFiパスワード";
```

> [!NOTE]
> WiFiに接続できない場合でも動作しますが、ファイル名が連番になり、Webギャラリーは利用できません。

### 2. ハードウェアの準備

1. **外部アンテナをXIAO ESP32S3に接続**（IPEXコネクタ）
2. microSDカードをFAT32でフォーマット
3. XIAO拡張基板のSDカードスロットに挿入
4. 拡張基板にXIAO ESP32S3を装着

### 3. 書き込みと実行

```bash
pio run --target upload
pio device monitor
```

## 使い方

### Webギャラリーへのアクセス

書き込み後、シリアルモニタに表示されるIPアドレスにアクセス：

```
WiFi: OK
IP: 192.168.1.100
Ready
```

ブラウザで `http://192.168.1.100` を開くと、以下の機能が利用できます：

#### ⚡ Liveタブ
- リアルタイムストリーム表示
- 解像度変更（QVGA～XGA）
- グレースケール切り替え
- Captureボタン: SDカードに保存（ストリーム継続）
- Reloadボタン: ストリーム再接続

#### 🖼️ Galleryタブ
- SDカード保存画像の一覧表示
- サムネイルクリックで拡大表示
- **Selectボタン**: 選択モードON/OFF
  - **All**: 全選択/解除
  - **Download**: 選択画像を一括ダウンロード
  - **Delete**: 選択画像を一括削除（確認あり）
- 削除時は「WARNING: N images will be permanently deleted.」の警告表示

## 動作確認

シリアルモニタで以下の出力を確認してください：

```
ESP32-S3 Camera
SD card: OK (32000MB)
Camera: OK
WiFi: OK
IP: 192.168.1.100
Ready
```

撮影時:
```
Saved: /20260216_154523.jpg
```

## 保存される画像

### ファイル名形式

WiFi接続成功時（NTP時刻同期あり）:
```
/20260211_153000.jpg
/20260211_154000.jpg
/20260211_155000.jpg
```

WiFi接続失敗時:
```
/image_0000.jpg
/image_0001.jpg
/image_0002.jpg
```

### 画像仕様

- デフォルト解像度: VGA (640x480)
- 形式: JPEG
- 品質: 10 (PSRAMあり) / 12 (PSRAMなし)
- 平均ファイルサイズ: 30-50KB

## 撮影間隔の変更

`src/main.cpp`の以下の行を編集：

```cpp
const unsigned long CAPTURE_INTERVAL = 10 * 60 * 1000;  // ミリ秒単位
```

例：
- 5分間隔: `5 * 60 * 1000`
- 30分間隔: `30 * 60 * 1000`
- 1時間間隔: `60 * 60 * 1000`

## 解像度について

Webブラウザから以下の解像度を選択可能：

- `QVGA` - 320x240（最小、軽量）
- `CIF` - 400x296
- `VGA` - 640x480（デフォルト、推奨）
- `SVGA` - 800x600
- `XGA` - 1024x768（最大、高負荷）

> [!WARNING]
> HD (1280x720) や UXGA (1600x1200) はESP32S3のストリーミングには負荷が高すぎるため、選択できません。

## トラブルシューティング

### WiFi接続が不安定/接続できない

> [!IMPORTANT]
> **最も重要**: 外部アンテナを接続してください。アンテナなしでは安定したWiFi接続は不可能です。

その他の確認事項：
- SSID/パスワードが正しいか確認
- 2.4GHz WiFiに接続しているか確認（5GHzは非対応）
- ルーターとの距離が近すぎないか確認（1m以上推奨）

### SDカードが認識されない

`SD_TROUBLESHOOTING.md` を参照してください。要点：

1. SDカードがFAT32でフォーマットされているか確認
2. SDカードが正しく挿入されているか確認
3. 拡張基板とXIAOの接続を確認
4. シリアルモニタで「SD card: Failed」を確認
5. 別のSDカードで試す（2-32GB、SDHC推奨）

### Webギャラリーにアクセスできない

- WiFiに正常に接続されているか確認（シリアルモニタで「WiFi: OK」）
- IPアドレスが正しいか確認
- ファイアウォールでポート80, 81が開いているか確認
- ブラウザのキャッシュをクリア

### Galleryタブで画像が読み込まれない

- ストリームタブからGalleryタブに切り替えてください（自動的にストリームが停止されます）
- Refreshボタンを押してください
- SDカードに画像が保存されているか確認

### メモリ不足で動作が不安定

解像度を下げてください（WebブラウザからQVGA/CIFに変更）

## SDカードの容量目安

保存された画像数の目安：
```
VGA (640x480) 1枚あたり約40KB
1GB SDカード = 約25,000枚
32GB SDカード = 約800,000枚
```

10分間隔で撮影した場合：
- 1日: 144枚 (約5.7MB)
- 1週間: 1,008枚 (約40MB)
- 1ヶ月: 4,320枚 (約170MB)

## ピン配置

### SDカード（SD_MMC 1ビットモード）

XIAO ESP32S3 Sense 拡張基板使用時：

| 機能 | GPIO | 説明 |
|------|------|------|
| CLK  | 7    | クロック |
| CMD  | 9    | コマンド |
| D0   | 8    | データ0 |

> [!IMPORTANT]
> SD_MMC 1ビットモードを使用しています。SPI方式ではありません。

### Webサーバー

| ポート | 用途 |
|--------|------|
| 80 | API・ページ・画像配信 |
| 81 | ストリーム専用 |

この2ポート構成により、ストリーム中でもAPI呼び出しがブロックされません。

## 消費電力について

- 待機時: 約80-100mA
- 撮影時: 約200-300mA (瞬間的)
- WiFi接続時（ストリーミング）: 約150-250mA

長時間動作させる場合は、安定した電源供給（USB 5V 500mA以上）が必要です。
