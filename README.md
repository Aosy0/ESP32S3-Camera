# ESP32-S3 Camera Auto Save to SD Card

XIAO ESP32S3 Sense用の自動撮影・SDカード保存プログラムです。10分ごとに自動撮影し、SDカードに保存します。Webブラウザから画像閲覧・管理も可能です。

## 機能

- **自動撮影**: 10分間隔で自動的に撮影
- **SDカード保存**: タイムスタンプ付きファイル名で保存
- **クラウドアップロード**: 撮影画像をGoogle Cloudへ自動アップロード（オプション）
- **Webギャラリー**: ブラウザからライブストリーム表示・画像閲覧
  - ライブストリーム（ポート81）
  - 解像度・グレースケール切り替え
  - ワンクリックキャプチャ（SDに自動保存）
  - アップロードON/OFF切り替え
  - SDカード画像の一覧表示・削除・ダウンロード
  - 一括選択・一括ダウンロード・一括削除機能
- **WiFi + NTP**: 正確な日本時間（JST）を取得
- **安定動作**: VGA解像度で安定した長時間動作
- **状態監視**: シリアルモニタでステータス確認可能

## 必要なハードウェア

- Seeed Studio XIAO ESP32S3 Sense
- XIAO ESP32S3 Sense 拡張基板
- **外部WiFiアンテナ（必須）**
- microSDカード（FAT32フォーマット、2-32GB推奨）
- WiFi環境（2.4GHz）

> [!IMPORTANT]
> **外部アンテナは必須です**。XIAO ESP32S3にアンテナを接続しないと、WiFi接続が非常に不安定になり、正常に動作しません。必ずアンテナを取り付けてください。

## クイックスタート

### ステップ1: WiFi設定

```bash
# config.h.exampleをコピー
cp src/config.h.example src/config.h

# config.hを編集してWiFi情報を入力
```

```cpp
const char* WIFI_SSID = "あなたのWiFi名";
const char* WIFI_PASSWORD = "あなたのWiFiパスワード";

// クラウドアップロード（オプション）
const char* UPLOAD_URL = "https://your-cloud-function-url";
const char* API_KEY = "your-api-key";
```

### ステップ2: ハードウェア準備

1. **外部アンテナをXIAO ESP32S3に接続**（IPEXコネクタ）
2. microSDカードをFAT32でフォーマット
3. XIAO拡張基板のSDカードスロットに挿入
4. 拡張基板にXIAO ESP32S3を装着

### ステップ3: 書き込みと実行

```bash
pio run --target upload
pio device monitor
```

## 保存される画像

### ファイル名形式

WiFi接続成功時（日本時間）:
```
/20260219_183000.jpg
/20260219_184000.jpg
```

WiFi接続失敗時:
```
/image_0000.jpg
/image_0001.jpg
```

### 画像仕様

- デフォルト解像度: VGA (640x480)
- 形式: JPEG
- 品質: 10 (PSRAMあり) / 12 (PSRAMなし)
- 平均ファイルサイズ: 30-50KB

## 設定

### 撮影間隔の変更

`src/main.cpp`の以下の行を編集：

```cpp
const unsigned long CAPTURE_INTERVAL = 10 * 60 * 1000;  // ミリ秒単位
```

例：
- 5分間隔: `5 * 60 * 1000`
- 30分間隔: `30 * 60 * 1000`
- 1時間間隔: `60 * 60 * 1000`

### 解像度について

Webブラウザから以下の解像度を選択可能：

- `QVGA` - 320x240（最小、軽量）
- `CIF` - 400x296
- `VGA` - 640x480（デフォルト、推奨）
- `SVGA` - 800x600
- `XGA` - 1024x768（最大、高負荷）

## SDカードの容量目安

```
VGA (640x480) 1枚あたり約40KB
1GB SDカード = 約25,000枚
32GB SDカード = 約800,000枚
```

10分間隔で撮影した場合：
- 1日: 144枚 (約5.7MB)
- 1週間: 1,008枚 (約40MB)
- 1ヶ月: 4,320枚 (約170MB)

## トラブルシューティング

### WiFi接続が不安定/接続できない

> [!IMPORTANT]
> **最も重要**: 外部アンテナを接続してください。アンテナなしでは安定したWiFi接続は不可能です。

その他の確認事項：
- SSID/パスワードが正しいか確認
- 2.4GHz WiFiに接続しているか確認（5GHzは非対応）
- ルーターとの距離が近すぎないか確認（1m以上推奨）

### SDカードが認識されない

#### チェック項目

1. **SDカードのフォーマット確認**
   - FAT32でフォーマットする必要があります
   - 32GB以下のSDカードを推奨（64GB以上はexFATになる可能性）

2. **物理的な接続確認**
   - SDカードをカチッと音がするまでしっかり押し込む
   - 拡張基板にXIAOがしっかり装着されているか確認

3. **SDカードの接点清掃**
   - SDカードの金属接点を柔らかい布で拭く

4. **別のSDカードで試す**
   - 2GB～32GBのSDHCを推奨

#### 推奨SDカード

- SanDisk Ultra 16GB/32GB (SDHC)
- Samsung EVO Plus 32GB (SDHC)
- Transcend 8GB/16GB (SDHC)

#### 非推奨

- 64GB以上（exFAT形式になりやすい）
- ノーブランド品（相性問題が発生しやすい）

### Webギャラリーにアクセスできない

- WiFiに正常に接続されているか確認
- IPアドレスが正しいか確認
- ファイアウォールでポート80, 81が開いているか確認

### アップロードが失敗する

- `UPLOAD_URL`と`API_KEY`が正しく設定されているか確認
- WiFi接続が安定しているか確認
- シリアルモニタでエラーメッセージを確認

### メモリ不足で動作が不安定

解像度を下げてください（WebブラウザからQVGA/CIFに変更）

## よくある質問

### Q: WiFiなしで使えますか？
A: はい。WiFiがなくても撮影・保存は可能です。ただしファイル名が連番になり、Webギャラリーは利用できません。

### Q: 撮影間隔を変更できますか？
A: `src/main.cpp`の`CAPTURE_INTERVAL`を変更してください。

### Q: どのくらいの枚数が保存できますか？
A: 32GBのSDカードで約800,000枚（VGA画質）保存可能です。

### Q: バッテリー動作は可能ですか？
A: 可能ですが、安定した電源供給（5V 500mA以上）が推奨されます。

### Q: SDカードなしでもカメラは動作しますか？
A: はい。SDカードが認識されなくても、カメラとWebサーバーは正常に動作します。自動保存のみ無効化されます。

## ピン配置

### SDカード（SD_MMC 1ビットモード）

| 機能 | GPIO | 説明 |
|------|------|------|
| CLK  | 7    | クロック |
| CMD  | 9    | コマンド |
| D0   | 8    | データ0 |

> [!IMPORTANT]
> SD_MMC 1ビットモードを使用しています。SPI方式ではありません。

### Webサーバー

| ポート | 用途 |
|--------|------|
| 80 | API・ページ・画像配信 |
| 81 | ストリーム専用 |

## 消費電力について

- 待機時: 約80-100mA
- 撮影時: 約200-300mA (瞬間的)
- WiFi接続時（ストリーミング）: 約150-250mA

長時間動作させる場合は、安定した電源供給（USB 5V 500mA以上）が必要です。
